# Microwave-Oven-Using-PIC16F877A-Microcontroller
Embedded C-based microwave oven controller using PIC16F877A with Micro, Grill and Convection modes, Start/Pause/Stop controls, CLCD, matrix keypad, timers and interrupts. Developed and tested in PICSimLab, gaining hands-on experience in embedded firmware and peripheral interfacing.
